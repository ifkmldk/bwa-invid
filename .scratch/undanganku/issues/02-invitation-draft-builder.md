# 02: Invitation Draft Builder

**What to build:**
An end-to-end invitation creation flow where a logged-in user can browse templates, pick one, and fill a step-by-step draft with the core wedding details needed to prepare a publishable invitation.

**Blocked by:**
01: Foundation & Auth Shell

**Status:** ready-for-agent

## Acceptance criteria
- [ ] Users can browse a template catalog grouped by category and choose a template to start a new invitation draft.
- [ ] The editor supports a guided multi-step flow for couple details, event details, gallery, love story, and gift info.
- [ ] Draft progress is saved so a user can leave and return without losing progress.
- [ ] Each step validates required inputs before allowing the user to continue.
- [ ] The invitation can be saved as a draft that is ready for publication later.
