# 06: Admin Template & Category Management

**What to build:**
An admin-facing catalog tool for creating, editing, and activating templates and categories, with locked template theme settings that stay consistent in public rendering.

**Blocked by:**
01: Foundation & Auth Shell

**Status:** ready-for-agent

## Acceptance criteria
- [ ] Admins can create, update, publish, and deactivate templates from a protected admin area.
- [ ] Admins can create, update, and reorder template categories.
- [ ] Template theme settings are editable by admins but remain locked from end-user override.
- [ ] Template previews are available before a template is published to the catalog.
- [ ] The catalog state is reflected consistently between admin and public views.
