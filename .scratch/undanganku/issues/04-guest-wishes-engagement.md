# 04: Guest Wishes & Engagement

**What to build:**
A public guest interaction flow where visitors can send wishes, read recent wishes, and see new messages appear without reloading the page.

**Blocked by:**
03: Public Invitation Runtime

**Status:** ready-for-agent

## Acceptance criteria
- [ ] Guests can submit a wish with a name and message from the public invitation page without logging in.
- [ ] Wishes are validated and rate limited to reduce spam and abuse.
- [ ] Recent wishes are visible on the invitation page in a clear, chronological feed.
- [ ] New wishes appear in the UI quickly enough that the page feels alive without a hard refresh.
- [ ] The flow remains simple enough for non-technical guests to use in a few taps.
