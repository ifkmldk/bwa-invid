# 03: Public Invitation Runtime

**What to build:**
A public invitation experience that renders a published invitation at its slug, uses the template's locked theme, and displays the event story clearly on desktop and mobile.

**Blocked by:**
02: Invitation Draft Builder

**Status:** ready-for-agent

## Acceptance criteria
- [ ] A published invitation is reachable through a public slug and renders without requiring login.
- [ ] The public page uses the template's locked theme settings and does not allow end-user theme overrides.
- [ ] The page shows the core invitation content, including events, gallery, love story, and gift information.
- [ ] The page is responsive and readable on mobile-first layouts while staying polished on desktop.
- [ ] The page includes sensible SEO metadata for shareable public links.
