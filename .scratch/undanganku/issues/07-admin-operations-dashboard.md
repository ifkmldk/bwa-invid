# 07: Admin Operations Dashboard

**What to build:**
A business operations dashboard where admins can monitor users, invitations, and payments in one place with search and filtering.

**Blocked by:**
05: Subscription Billing & Limits

**Status:** ready-for-agent

## Acceptance criteria
- [ ] Admins can see high-level counts for users, active invitations, and recent revenue.
- [ ] Admins can review user records with plan, invitation count, and account status.
- [ ] Admins can review payment records with status, amount, and payment metadata.
- [ ] Search and filtering work on the operational lists so support work is practical.
- [ ] Access to the dashboard is restricted to admin users only.
